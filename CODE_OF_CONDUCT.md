# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the work, not the person.
Harassment, personal attacks and discrimination are not tolerated.

Report problems privately to the maintainer through a
[private security advisory](https://github.com/marcopesani/swarm-skill/security/advisories/new)
(choose it even if the problem is not technical) or by email to the address on the maintainer's GitHub profile.
Reports are kept confidential.
